# LEXIA — Cabinet d'agents juridiques IA

Application installable (PWA) pour Android et ordinateur : 15 agents juridiques spécialisés en droit OHADA, UEMOA, CIMA, BCEAO et ivoirien.

- **Ouvrir l'application :** https://jeanangemichael-droid.github.io/lexia/
- Installation : Chrome → menu ⋮ → « Installer l'application ».
- Toutes les données sont chiffrées (AES-256) sur l'appareil ; ce dépôt ne contient que le code, aucune donnée ni clé.
- Serveur dédié facultatif pour une équipe : `serveur-cabinet/server.js`.
